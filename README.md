# po8klasie web frontend
:poland: Prawdopodobnie najprostsza i najszybsza wyszukiwarka szkół średnich. <br/>

:uk: Probably the simplest and fastest high schools lookup service. <br />

We are in the process of migrating project to the new architecture.
Presentation layer is being rewritten to react-router v7.

That migration will allow us to:
* modularize the codebase
* improve performance
* simplify data flow
* simplify selfhosting
